# AR Aging, Multi-Currency GST Ledger & Invoice Framework

A production-ready financial operations and Accounts Receivable (AR) management framework built with Advanced MS Excel formulas, dynamic aging buckets, and multi-currency exchange rate tracking. Designed for SaaS, cloud hosting, and enterprise billing departments.

## 📊 Framework Overview
This repository provides a standardized bookkeeping workbook that eliminates manual reconciliation errors, automates GST tax calculations (CGST/SGST/IGST), and provides real-time visibility into customer cash flows.

### Core Worksheets Included:
1. **AR Aging Dashboard**: Executive summary featuring KPI metric cards and a dynamic 30/60/90-day overdue portfolio breakdown.
2. **Master Ledger & GST Invoices**: Transaction database featuring automated tax calculations, multi-currency conversion links, and aging status tracking.
3. **Multi-Currency Tracker**: Benchmark exchange rates for USD, EUR, and INR conversion.

---

## 🚀 Key Features & Formulas
- **Dynamic Aging Analysis**: Uses conditional counting and summing formulas (`COUNTIF`, `SUMIF`) to automatically categorize outstanding client balances into *Current*, *30-60 Days*, and *60+ Days Overdue*.
- **Automated GST Computation**: Applies standard tax rates (18%) directly to base amounts with clean rounding formatting.
- **Multi-Currency Conversion**: Links foreign currency invoices directly to live exchange benchmark cells.
